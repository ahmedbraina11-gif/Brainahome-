إدارة وتحديث صور الموقع فورياً

يمكنك تعديل روابط الصور أو استبدالها بمسارات مجلدك المحلي مثل `assets/images/sofa.jpg` وستحفظ تلقائياً دون الحاجة لتعديل الكود.

دليل التنصيب والنشر على Netlify و GitHub

سبب ظاهرة الصفحة البيضاء والحل المباشر:

تظهر الصفحة بيضاء عندما يتعذر على المتصفح العثور على ملفات الصور المسجلة في الروابط أو عند استخدام مسارات غير موجودة مثل assets/images/ بدون رفع الصور الفعلية إليها.

الخطوات الشاملة للرفع والتنصيب:

  1. إنشاء مجلد المشروع المحلي: أنشئ مجلداً جديداً على جهازك باسم braina-home وضغ بداخله هذا الملف باسم index.html.
  2. مجلد الصور assets: أنشئ مجلداً فرعياً داخل مشروعك بالمسار assets/images/ وضغ بداخله كافة الصور التي تود استخدامها.
  3. الرفع على GitHub: قم برفع مجلد المشروع كاملاً إلى مستودعك (Repository) على GitHub بنفس الهيكلية تماماً.
  4. الربط والتحديث التلقائي مع Netlify: ربط مستودع GitHub بـ Netlify سيضمن تحديث موقعك المباشر تلقائياً وبشكل فوري بمجرد رفع أي صور أو تعديلات جديدة.
